md is a Markdown editor and live previewer for iPhone and iPad. This update (1.5) adds find and replace, typing that continues lists, quotes and tables and capitalizes sentences, hardware-keyboard shortcuts on iPad, and support for every Markdown file extension.

1. ACCESS — NOTHING TO SET UP
No account, no sign-in, no registration, no in-app purchases, no subscriptions. Every feature works the moment the app launches, so no demo credentials exist or are needed.

No test file is needed: the app ships with sample documents. Open any document, tap the Examples button in the toolbar (on iPhone, in its three-dot More menu) and pick one (Welcome, Formatting, Tables, Code, Images, Math, Diagrams, Writer Tools).

2. A THREE-MINUTE WALKTHROUGH OF WHAT IS NEW
a) Tap New Document on the opening screen and type Markdown; the preview follows. Return continues a list item, a quote or a table row, and the first letter of each line and sentence is capitalized. Both are switches in the toolbar's Typing menu.
b) Tap Find in the toolbar, or Command-F on a hardware keyboard, for the system find panel, with Replace and Replace All on iPhone as well as iPad. It searches the source, not the preview.
c) On an iPad with a hardware keyboard: Command-1, 2 and 3 select Edit, Split and Preview, Command-P prints, Shift-Command-B shows the book, and Control-Command-Up and Down step through its articles.
d) Files open and save in place under every Markdown spelling (.md, .markdown, .mdown, .markdn, .mdtext, .mdtxt, .mkd, .mkdn, .mdwn, .mkdown), and as .txt, .puml, .plantuml, .iuml, .pu, .gv, .textbundle and .textpack.
e) Everything else is as before: the Examples menu (Math, Diagrams, Code, and Example Book for writer mode) and the Share button's exports to PDF, HTML, EPUB, LaTeX, TextBundle and SVG, each written where you pick in the Files browser.

The app creates no hidden files or sidecar metadata. Files and folders are reached only through the standard system document browser and folder picker, and folder access is kept as a security-scoped bookmark.

3. PURPOSE AND AUDIENCE
Writers, developers and students who keep notes, documentation or a book in plain Markdown files and want to see, print and export the finished page. Nothing is shared, published or hosted anywhere, so there is nothing to moderate, report or block.

4. NETWORK AND EXTERNAL SERVICES
The app contacts no servers of ours; there are none. It has no analytics, no advertising, no tracking, and it collects no data (the Privacy Nutrition Label answer is "Data Not Collected").

The app touches the network only when a document the user opened references an image by a remote URL: the renderer fetches that image so it can be shown and printed. That request goes to the host named in the user's own document. Nothing else is ever sent or fetched.

5. NO DOWNLOADED CODE (2.5.2)
Math, chemistry, diagrams and code highlighting are drawn by open-source JavaScript engines bundled inside the app and served to WKWebView from a private, offline scheme: KaTeX (with its mhchem extension), Mermaid, Graphviz, PlantUML, and highlight.js. No executable code is downloaded or updated at runtime, and no interpreted code comes from any server. There are no third-party Swift packages or SDKs.

6. PERMISSIONS
None are requested: no camera, microphone, location, contacts, calendars, notifications, or tracking prompt. Files are reached only through the system document browser and folder picker — the user always chooses what the app may touch.

7. REGIONAL DIFFERENCES, REGULATED CONTENT
None. The app behaves identically everywhere, contains no regulated or age-restricted content, and includes no third-party trademarked material beyond the open-source engines named above, each bundled under its own open-source licence.

Encryption: ITSAppUsesNonExemptEncryption is false — the app implements no encryption.

Minimum system: iOS and iPadOS 26. The source code and the privacy policy are public.
